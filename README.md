# Portfolio Website

Personal portfolio of **Fahad Qureshi**, Software Engineer working in machine learning, RAG, NLP, and FastAPI.

Built with React, Vite, Tailwind CSS, and Motion.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Deploys to Vercel as a Vite project (`vercel.json` handles client-side routing).
